# Bankkonto-Projekt

Ein einfaches Bankkonto-System in Java, entwickelt mit Test-Driven Development (TDD) und JUnit 5.

## Verwendete Konzepte

- Test-Driven Development (Red-Green-Refactor)
- Objektorientierte Programmierung (Vererbung, Kapselung)
- Exception Handling für Validierung (z. B. ungültige Beträge)
- Collections (ArrayList) zur Speicherung der Transaktionshistorie
- JUnit 5 (Assertions, @BeforeEach, assertThrows)

## Ausführen

Das Projekt kann über die `Main`-Klasse gestartet werden, die eine Demonstration der Funktionalität zeigt (Konto erstellen, ein-/auszahlen, Transaktionshistorie, Sparkonto mit Zinsen).

Die Tests lassen sich über JUnit 5 in einer IDE wie IntelliJ ausführen.
